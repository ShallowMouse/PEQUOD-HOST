# Hawthorne Link (sender)

These three files are copied unchanged from the Hawthorne repo (`Source/Network/`), so PEQUOD Host speaks exactly
the same protocol as Hawthorne's network receiver and the standalone Hawthorne Link sender. If the protocol
changes in Hawthorne, copy them again.

Last copied from Hawthorne commit db06b5d (self-sizing network buffer, bigger socket buffers, latency in the header).
